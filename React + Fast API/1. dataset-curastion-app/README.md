## Installation Instructions

Create Project

```bash
npm create vite@latest dataset-curations
```

Install Dependencies

```bash
npm install
```

Start Server

```bash
npm run dev
```

Install JSON Server

```bash
npm install json-server
```

Usage and Querying JSON Server is defined here : [typicode/json-server](https://github.com/typicode/json-server)

Install React Router

```bash
npm install react-router
```
